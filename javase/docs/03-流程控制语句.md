# 第3章：流程控制语句

## 知识点

### 1. 三种结构
顺序结构（默认逐行执行）、判断选择结构（if/switch）、循环结构（for/while/do...while）。

### 2. if 语句三种格式
- 格式1：`if (条件) { 语句 }`
- 格式2：`if (条件) { 语句1 } else { 语句2 }`
- 格式3：`if ... else if ... else`（多条件分支，自上而下匹配）
- 细节：语句体只有一行时大括号可省略（不建议）；`if` 小括号后不能加分号

### 3. switch 语句
```java
switch (表达式) {
    case 值1: 语句; break;
    case 值2: 语句; break;
    default: 语句;
}
```
- 表达式类型：byte/short/int/char/String/枚举
- case 穿透：不写 break 会继续执行下一个 case（可用于合并多分支）
- default 位置不限，一般放最后

### 4. 三种循环
- `for (初始化; 条件; 步进) { 循环体 }`：已知次数/范围
- `while (条件) { 循环体 }`：只知道结束条件
- `do { 循环体 } while (条件);`：先执行后判断，至少执行一次

### 5. 无限循环
`for(;;)`、`while(true)`、`do...while(true)`；最常用 while；无限循环后面不能再写代码（执行不到）。

### 6. break 与 continue
- `break`：用在 switch/循环中，结束并跳出
- `continue`：只能用在循环中，跳过本次、继续下次

### 7. Random
```java
Random r = new Random();      // 需要 import java.util.Random;
int n = r.nextInt(100);       // 0~99
int n2 = r.nextInt(100) + 1;  // 1~100
```

### 8. 循环嵌套
外层循环控制次数，内层循环是核心。每执行一次外循环，内循环完整跑一轮。`\t` 制表符用于对齐输出（如九九乘法表）。

### 4. 优惠券最优价（if格式3）

源文件：`BestCoupon.java`

```java
import java.util.Scanner;

public class BestCoupon {
    public static void main(String[] args) {
        // 优惠券：满10减8/满50减30/满100减50/满200减90；会员卡8折（二选一）
        Scanner sc = new Scanner(System.in);
        System.out.println("请输入商品总价：");
        double price = sc.nextDouble();

        // 方案一：使用优惠券
        double couponPrice;
        if (price >= 200) {
            couponPrice = price - 90;
        } else if (price >= 100) {
            couponPrice = price - 50;
        } else if (price >= 50) {
            couponPrice = price - 30;
        } else if (price >= 10) {
            couponPrice = price - 8;
        } else {
            couponPrice = price;
        }

        // 方案二：使用会员卡
        double vipPrice = price * 0.8;

        System.out.println("优惠券价格：" + couponPrice);
        System.out.println("会员卡价格：" + vipPrice);

        double best = couponPrice < vipPrice ? couponPrice : vipPrice;
        System.out.println("最优惠价格：" + best);
    }
}
```

### 8. 求数位之和（while）

源文件：`DigitSum.java`

```java
import java.util.Scanner;

public class DigitSum {
    public static void main(String[] args) {
        // 数位之和：给定整数n，计算所有数位之和，负数先取绝对值
        Scanner sc = new Scanner(System.in);
        System.out.println("请输入一个整数：");
        int number = sc.nextInt();

        // 负数取绝对值
        if (number < 0) {
            number = -number;
        }

        int sum = 0;
        while (number != 0) {
            sum = sum + number % 10;
            number = number / 10;
        }

        System.out.println("数位之和：" + sum);
    }
}
```

### 9. 游戏血量计算+输入校验（break）

源文件：`GameHp.java`

```java
import java.util.Scanner;

public class GameHp {
    public static void main(String[] args) {
        // 游戏血量：初始200，受到X点伤害，恢复Y点血，X和Y必须大于0否则重新录入
        Scanner sc = new Scanner(System.in);
        int hp = 200;

        int hurt;
        while (true) {
            System.out.println("请输入受到的伤害值（大于0）：");
            hurt = sc.nextInt();
            if (hurt > 0) {
                break;
            }
            System.out.println("伤害值不合法，请重新录入");
        }

        int recover;
        while (true) {
            System.out.println("请输入恢复的血量（大于0）：");
            recover = sc.nextInt();
            if (recover > 0) {
                break;
            }
            System.out.println("恢复值不合法，请重新录入");
        }

        hp = hp - hurt + recover;

        // 游戏人物不会死亡，最少1点血
        if (hp < 1) {
            hp = 1;
        }

        System.out.println("最终血量：" + hp);
    }
}
```

### 10. 判断质数（break）

源文件：`PrimeCheck.java`

```java
import java.util.Scanner;

public class PrimeCheck {
    public static void main(String[] args) {
        // 找质数：键盘录入一个大于等于2的整数，判断是否为质数
        Scanner sc = new Scanner(System.in);
        System.out.println("请输入一个大于等于2的整数：");
        int number = sc.nextInt();

        boolean isPrime = true;
        for (int i = 2; i < number; i++) {
            if (number % i == 0) {
                isPrime = false;
                break;
            }
        }

        if (isPrime) {
            System.out.println(number + " 是质数");
        } else {
            System.out.println(number + " 不是质数");
        }
    }
}
```

### 12. 猜数字游戏（无限循环+Random）

源文件：`GuessNumber.java`

```java
import java.util.Random;
import java.util.Scanner;

public class GuessNumber {
    public static void main(String[] args) {
        // 猜数字：程序生成1-100随机数，循环猜直到猜中
        Random r = new Random();
        int answer = r.nextInt(100) + 1;
        Scanner sc = new Scanner(System.in);

        while (true) {
            System.out.println("请输入你猜的数字（1-100）：");
            int guess = sc.nextInt();

            if (guess > answer) {
                System.out.println("猜大了");
            } else if (guess < answer) {
                System.out.println("猜小了");
            } else {
                System.out.println("恭喜你，猜中了！");
                break;
            }
        }
    }
}
```

### 13. 长方形/三角形/倒三角/梯形/平行四边形

源文件：`ShapePrinter.java`

```java
public class ShapePrinter {
    public static void main(String[] args) {
        // 案例一：打印长方形（5行8列）
        for (int i = 1; i <= 5; i++) {
            for (int j = 1; j <= 8; j++) {
                System.out.print("* ");
            }
            System.out.println();
        }
        System.out.println("--------------------");

        // 案例二：打印正三角形（5行）
        for (int i = 1; i <= 5; i++) {
            for (int j = 1; j <= i; j++) {
                System.out.print("* ");
            }
            System.out.println();
        }
        System.out.println("--------------------");

        // 案例三：打印倒三角形（5行）
        for (int i = 5; i >= 1; i--) {
            for (int j = 1; j <= i; j++) {
                System.out.print("* ");
            }
            System.out.println();
        }
        System.out.println("--------------------");

        // 案例四：打印梯形（5行，上底4，每行多2个）
        for (int i = 1; i <= 5; i++) {
            for (int j = 1; j <= 4 + 2 * (i - 1); j++) {
                System.out.print("* ");
            }
            System.out.println();
        }
        System.out.println("--------------------");

        // 案例五：打印平行四边形（5行5列，逐行左移）
        for (int i = 1; i <= 5; i++) {
            for (int j = 1; j <= 5 - i; j++) {
                System.out.print("  ");
            }
            for (int j = 1; j <= 5; j++) {
                System.out.print("* ");
            }
            System.out.println();
        }
    }
}
```
