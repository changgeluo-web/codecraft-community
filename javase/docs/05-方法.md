# 第5章：方法

## 知识点

### 1. 概念
方法是完成特定功能的代码块，提高代码复用性。

### 2. 通用格式
```java
public static 返回值类型 方法名(参数列表) {
    方法体;
    return 数据;   // 有返回值时
}
```
定义方法时做到"两个明确"：明确返回值类型、明确参数的类型和数量。

### 3. 三种形态
- 无参数无返回值：`public static void xxx() { }`，直接调用
- 带参数：形参（定义时的占位变量）接收实参（调用时的真实数据）
- 带返回值：用变量接收调用结果，`return` 后方法结束

### 4. 注意事项
- 方法不能嵌套定义
- `void` 方法可以省略 return，或单独写 `return;`（不接数据）
- 调用：void 方法直接调用；非 void 方法推荐用变量接收

### 5. 方法重载
同一个类中，方法名相同、参数列表不同（类型或个数不同）的多个方法互为重载。
- 与返回值无关：不能仅靠返回值区分重载
- 调用时由参数自动匹配对应版本

### 2. 10个不重复随机数（方法封装）

源文件：`UniqueRandomArray.java`

```java
import java.util.Random;

public class UniqueRandomArray {
    public static void main(String[] args) {
        // 获取10个1-100之间不重复的随机数，用方法实现
        int[] arr = getUniqueRandomArray(10, 1, 100);
        printArray(arr);
    }

    public static int[] getUniqueRandomArray(int length, int min, int max) {
        Random r = new Random();
        int[] arr = new int[length];
        int count = 0;
        while (count < length) {
            int number = r.nextInt(max - min + 1) + min;
            if (!contains(arr, count, number)) {
                arr[count] = number;
                count++;
            }
        }
        return arr;
    }

    public static boolean contains(int[] arr, int size, int number) {
        for (int i = 0; i < size; i++) {
            if (arr[i] == number) {
                return true;
            }
        }
        return false;
    }

    public static void printArray(int[] arr) {
        for (int i = 0; i < arr.length; i++) {
            System.out.print(arr[i] + " ");
        }
        System.out.println();
    }
}
```

### 3. 方法：单行格式遍历数组

源文件：`PrintArray.java`

```java
public class PrintArray {
    public static void main(String[] args) {
        // 数组遍历：结果在一行上，例如[11, 22, 33, 44, 55]
        int[] arr = {11, 22, 33, 44, 55};
        printArray(arr);
    }

    public static void printArray(int[] arr) {
        System.out.print("[");
        for (int i = 0; i < arr.length; i++) {
            if (i == arr.length - 1) {
                System.out.print(arr[i]);
            } else {
                System.out.print(arr[i] + ", ");
            }
        }
        System.out.println("]");
    }
}
```

```java
public class MultiplicationTableMethod {
    public static void main(String[] args) {
        // 设计一个方法打印九九乘法表
        printMultiplicationTable();
    }

    public static void printMultiplicationTable() {
        for (int i = 1; i <= 9; i++) {
            for (int j = 1; j <= i; j++) {
                System.out.print(j + "*" + i + "=" + (i * j) + "\t");
            }
            System.out.println();
        }
    }
}
```

### 6. 作业：评委打分（去最高最低求平均）

源文件：`JudgeScore.java`

```java
import java.util.Scanner;

public class JudgeScore {
    public static void main(String[] args) {
        // 评委打分：5个评委0-100分，去掉最高分和最低分，剩余求平均
        Scanner sc = new Scanner(System.in);
        int[] scores = new int[5];

        for (int i = 0; i < scores.length; i++) {
            while (true) {
                System.out.println("请输入第" + (i + 1) + "个评委的分数（0-100）：");
                int score = sc.nextInt();
                if (score >= 0 && score <= 100) {
                    scores[i] = score;
                    break;
                }
                System.out.println("分数超出范围，请重新录入");
            }
        }

        int max = getMax(scores);
        int min = getMin(scores);
        int sum = getSum(scores);

        double finalScore = (sum - max - min) * 1.0 / (scores.length - 2);

        System.out.println("最高分：" + max);
        System.out.println("最低分：" + min);
        System.out.println("总分：" + sum);
        System.out.println("选手最终得分：" + finalScore);
    }

    public static int getMax(int[] arr) {
        int max = arr[0];
        for (int i = 1; i < arr.length; i++) {
            if (arr[i] > max) {
                max = arr[i];
            }
        }
        return max;
    }

    public static int getMin(int[] arr) {
        int min = arr[0];
        for (int i = 1; i < arr.length; i++) {
            if (arr[i] < min) {
                min = arr[i];
            }
        }
        return min;
    }

    public static int getSum(int[] arr) {
        int sum = 0;
        for (int i = 0; i < arr.length; i++) {
            sum = sum + arr[i];
        }
        return sum;
    }
}
```

### 7. 作业：班级成绩统计（及格率/平均分/最高分）

源文件：`ClassScore.java`

```java
import java.util.Scanner;

public class ClassScore {
    public static void main(String[] args) {
        // 统计10名学生成绩：及格率、平均分、最高分
        Scanner sc = new Scanner(System.in);
        int[] scores = new int[10];

        for (int i = 0; i < scores.length; i++) {
            while (true) {
                System.out.println("请输入第" + (i + 1) + "名学生的成绩（0-100）：");
                int score = sc.nextInt();
                if (score >= 0 && score <= 100) {
                    scores[i] = score;
                    break;
                }
                System.out.println("成绩无效，请重新输入");
            }
        }

        int passCount = getPassCount(scores);
        double passRate = passCount * 1.0 / scores.length;
        double avgScore = getSum(scores) * 1.0 / scores.length;
        int max = getMax(scores);

        System.out.println("及格人数：" + passCount);
        System.out.println("及格率：" + (passRate * 100) + "%");
        System.out.println("平均分：" + avgScore);
        System.out.println("最高分：" + max);
    }

    public static int getPassCount(int[] arr) {
        int count = 0;
        for (int i = 0; i < arr.length; i++) {
            if (arr[i] >= 60) {
                count++;
            }
        }
        return count;
    }

    public static int getSum(int[] arr) {
        int sum = 0;
        for (int i = 0; i < arr.length; i++) {
            sum = sum + arr[i];
        }
        return sum;
    }

    public static int getMax(int[] arr) {
        int max = arr[0];
        for (int i = 1; i < arr.length; i++) {
            if (arr[i] > max) {
                max = arr[i];
            }
        }
        return max;
    }
}
```

### 8. 作业：快递邮费计算（分段计价）

源文件：`ExpressFee.java`

```java
import java.util.Scanner;

public class ExpressFee {
    public static void main(String[] args) {
        // 快递邮费：首重1kg 10元；超1-5kg每kg加2元；超5kg每kg加1.5元；不足1kg按1kg算
        Scanner sc = new Scanner(System.in);
        double weight;
        while (true) {
            System.out.println("请输入快递重量（kg，必须大于0）：");
            weight = sc.nextDouble();
            if (weight > 0) {
                break;
            }
            System.out.println("重量不合法，请重新输入");
        }

        double fee = calculateFee(weight);
        System.out.println("快递运费：" + fee + "元");
    }

    public static double calculateFee(double weight) {
        // 不足1kg按1kg算：向上取整
        int kg = (int) Math.ceil(weight);

        double fee = 10;
        if (kg > 5) {
            fee = fee + (5 - 1) * 2 + (kg - 5) * 1.5;
        } else if (kg > 1) {
            fee = fee + (kg - 1) * 2;
        }
        return fee;
    }
}
```
