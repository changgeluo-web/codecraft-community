# 第6章：Java的运行原理

## 知识点

### 1. 运行机制
1. 编写 `.java` 源文件（给程序员看）
2. 编译成 `.class` 字节码文件（给机器看）
3. 字节码运行在 JVM（Java虚拟机）中

### 2. 跨平台
- JVM 是针对不同操作系统的"虚拟操作系统"，字节码运行在 JVM 上
- 同一套代码安装不同平台的 JDK（内含 JVM）即可在任意系统运行 → 跨平台
- 好处：降低开发成本，一份代码多平台运行

### 3. 内存与内存地址
- 内存（RAM）：软件运行时临时存储数据的地方，断电/关闭即丢失
- 内存地址：内存中每个存储单元的编号，用于定位数据

### 4. JVM 内存分配（简化）
- 栈内存：存放方法调用、局部变量，方法结束即释放
- 堆内存：存放 `new` 出来的对象/数组
- 方法区：存放类信息、静态内容（了解）

### 5. 变量在内存中的情况
- 基本类型变量：栈中直接存值
- 数组/对象：栈中存引用（地址），数据在堆中

### 6. 方法参数传递
- 基本类型：传的是**值的副本**，方法内修改不影响原变量
- 数组/对象：传的是**地址的副本**，方法内修改元素会影响原数组
