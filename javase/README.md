## 运行方式

每个 `.java` 文件都是独立可运行程序（含 `main` 方法）：

```bash
cd src/chapter02
javac -encoding UTF-8 *.java
java RedPacketBalance
```

含键盘录入（`Scanner`）的程序运行时按提示输入即可。
